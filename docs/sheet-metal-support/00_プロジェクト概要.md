# 1. プロジェクト名

**板金製造支援システム**
## 設計と現場をつなぐ判断支援プラットフォーム 

---

# 2. プロジェクト概要

板金製造支援システムは、設計から曲げ加工までの情報を一元管理し、曲げ加工の標準化・技術継承・属人化の解消を目的とした製造支援システムである。

本システムは、単なる加工手順書や作業支援ツールではなく、会社独自の加工ノウハウを蓄積し、将来的にはAIによる加工支援まで発展可能な製造プラットフォームを目指す。

また、本システムは既存の「ポータルアプリ」の一機能として開発し、図面ライブラリ・工程管理など既存システムとの連携を前提とする。

---

# 3. プロジェクトの背景

現在の曲げ加工は、現場技術者の経験や判断に依存する部分が多い。

特に以下の内容は標準化されておらず、加工担当者によって品質や判断が異なる。

- 曲げ順
    
- 使用金型
    
- バックゲージ位置
    
- ワークの向き
    
- 加工時の注意事項
    

また、新規形状ではテスト加工を繰り返しながら加工条件を決定しており、その結果得られたノウハウが十分に共有・蓄積されていない。

このため、技術継承が難しく、属人化が進む要因となっている。

---

# 4. プロジェクトの目的

本プロジェクトでは、設計段階で加工条件を決定し、現場ではその情報を確認しながら加工できる環境を構築する。

また、新規加工で得られた知識を会社の資産として蓄積し、継続的に成長するナレッジベースを構築する。

目的は以下の通りである。

- 曲げ加工の標準化
    
- 技術継承
    
- 属人化の解消
    
- 加工品質の安定化
    
- テスト加工回数の削減
    
- 加工ノウハウの蓄積
    
- 将来的なAIによる加工支援
    

---

# 5. 最終目標

最終目標は、アマダのような製造支援環境を自社で構築することである。

ただし、既存製品を模倣することが目的ではなく、自社独自の加工ノウハウを蓄積し、自社に最適化された製造支援システムを構築することを目指す。

設計・加工・改善のサイクルをデータとして蓄積し、使うほど会社の技術資産が増えていくシステムを実現する。

---

# 6. 開発方針

本システムは「製造システム」として設計する。

単なる画面やデータベースではなく、加工ノウハウを判断できる「曲げ加工支援エンジン」を中心に構築する。

開発は段階的に進める。

1. 加工知識の蓄積
    
2. 加工条件の標準化
    
3. 3Dシミュレーション
    
4. 干渉判定
    
5. 加工条件自動提案
    
6. AIによる加工支援
    

---

# 7. システムの位置付け

本システムは、既存ポータルアプリの一機能として実装する。

将来的には以下のシステムと連携する。

- 図面ライブラリ
    
- 工程管理
    
- 部材管理
    
- CADデータ管理
    
- AI支援機能
    

---

# 8. 対象工程

本プロジェクトの対象工程は以下とする。

- 設計（SOLIDWORKS）
    
- 曲げ加工
    

レーザー加工・溶接・組立・検査については将来的な拡張対象とする。

# 10. 前提条件・関連システム

本システムは図面ライブラリとの連携を前提とする。

現状では、自社発行図面はトップアセンブリ単位でPDFを結合して管理しているため、部品単位で図面を取得・表示することができない。

曲げ加工支援システムでは部品単位で図面や加工情報を表示する必要があるため、図面ライブラリ側の管理方式についても改善を検討する。

この改善内容については、図面ライブラリの要件定義にて別途整理する。

---

# 11. ビジョン

板金製造支援システムは、単なる曲げ加工支援ソフトではない。

設計から加工までをデジタルでつなぎ、会社独自の製造技術を蓄積・継承する製造プラットフォームを構築することを目的とする。

使えば使うほど会社の技術資産が増え、技術継承・品質向上・生産性向上を実現する「成長する製造システム」を目指す。
