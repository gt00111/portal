# M-BEND連携設計

## 1. 目的

高難度な曲げ順序・3D干渉判定は、ポータル内へ重複実装せず、独立した板金CAM「M-BEND」が担当する。
板金製造支援は、図面・加工条件・技術情報と、M-BENDが生成した解析結果を品番単位でまとめて表示する。

## 2. 責務分担

- `portal-master.db`：機械コード・名称など、他アプリからも参照する設備識別情報。
- M-BEND：機械CAMプロファイル、上型、下型、ホルダー・中間板、3Dモデル、取付座標、CadLinkパッケージの読込、曲げ順序、金型選定、干渉解析、製造計画の正本。
- `sheet-metal-support.db`：M-BEND結果の取込履歴。CAM内部データの正本にはしない。
- 板金製造支援UI：M-BENDの起動、結果取込、作業者向け表示。

## 3. 連携方式

初期実装はDLL直結ではなく、JSONと別プロセスによる疎結合方式とする。

```text
portal-master.db
  -> M-BEND互換金型JSON
  -> M-BEND（別プロセス）
  -> *.sequence.json / *.simulation.json / *.tools.json
  -> sheet-metal-support.db.cam_results
  -> 板金製造支援「板金CAM」タブ
```

連携ファイルは、共通DBと同じデータルートの `integrations/m-bend/` 配下へ生成する。
M-BENDソースおよび既存設定ファイルは変更しない。M-BEND起動時の作業ディレクトリを連携フォルダーにし、生成した `mbend.config.json` を読ませる。

## 4. マスター変換

生成ファイルは次の4つ。

- `tools/machines.json`
- `tools/upper-punches.json`
- `tools/default-dies.json`
- `tools/setups.json`

機械専用金型は `m_upper_tool_machines`、`m_lower_tool_machines` を参照する。対応行がない金型は全機械共用として扱う。
`setups.json` は、各機械で使用可能な上型・下型の組合せから生成する。

ホルダー・中間板は現行M-BENDスキーマで直接読込できないため、機械JSONへ参考情報として出力する。実干渉判定へ使用するにはM-BEND側のスキーマ拡張が必要。

## 5. 結果取込

品番と同名の次のファイルを読み込む。

- `{品番}.simulation.json`（必須）
- `{品番}.sequence.json`（任意）
- `{品番}.tools.json`（任意）

取込時は結果を上書きせず `cam_results` に履歴追加する。画面は最新取込結果を表示する。
将来、CAM結果から加工条件を更新する場合も、利用者確認後の反映とし、自動上書きしない。

## 6. 現時点の制約

- M-BENDは .NET 8 SDKが必要。
- M-BEND WPFはWindows専用。
- 入力はGeneric CadLinkの `bend.json` と `flat.dxf` を前提とする。
- ホルダー・中間板、実金型メッシュ、バックゲージ形状の完全連携は未対応。
- M-BENDリポジトリにライセンスファイルがないため、ポータルへのソース複製は行わない。

## 7. 次の実装候補

1. M-BEND側にポータル連携スキーマの読込を追加し、ホルダー・中間板を正式対応する。
2. WPF起動時の `--config` と `--part` 引数を追加し、選択品番を直接開く。
3. Manufacturing Plan専用の安定した交換スキーマとバージョンを定義する。
4. CAM結果から加工条件へ反映する確認画面を追加する。
5. 公開・配布条件を明確にするためM-BENDへライセンスを追加する。

## 8. ポータル上のアプリ分離

M-BENDと板金製造支援は、ポータル上でも別アプリとして表示する。

- M-BEND：接続設定、CAM起動、機械・金型・3Dモデル管理。
- 板金製造支援：図面、M-BEND加工条件・曲げ順、技術ノート、加工履歴、ワーク3D、CAM結果確認。

移行期間中は共通マスターの既存機械・金型をM-BEND形式へ同期する。M-BEND側の専用マスターDBと管理画面が完成した後、共通マスター側のCAM固有項目を廃止する。

## 9. 加工動画連携

加工動画は画面録画ファイルを受け渡す方式ではなく、M-BENDのManufacturing Planを再生データとして板金製造支援へ渡す。
最低限、工程ごとに曲げID、開始・終了角度、ワーク姿勢、機械、上型、下型、バックゲージ位置、干渉イベントを持たせる。
板金製造支援はこの時系列データとワーク3Dモデルを使って再生する。これにより動画保存容量を増やさず、停止・コマ送り・視点変更ができる。
