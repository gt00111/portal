# 板金製造支援システム 開発タスク分解

本書は `12_開発ロードマップ.md` を実装タスクに分解したものである。今回の合意事項を前提とする。

- 図面ライブラリ：**まず実データの登録粒度を確認（REQ-DL-001）** し、範囲を確定してから着手。
- 初回リリース：**Phase 1（品番検索・最新版PDF表示）のみ** を対象に一度動かす。
- Phase 2 以降は本書に記載するが、着手は Phase 1 完了・現場検証後。
