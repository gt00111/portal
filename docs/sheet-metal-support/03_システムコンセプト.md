# 1. システムコンセプト

板金製造支援システムは、

**「技術の標準化」**

を目的とした製造支援プラットフォームである。

現場技術者が持つ経験・勘・ノウハウをデータとして蓄積し、誰でも同じ品質で加工できる環境を構築する。

本システムは単なる加工支援ソフトではなく、

会社独自の製造技術を資産として蓄積・継承・発展させることを目的とする。

---

# 2. システムコンセプト図

```text
設計（SOLIDWORKS）
        │
        ▼
      品番
        │
        ▼
曲げシミュレーションエンジン
        │
        ├─ 3Dシミュレーション
        ├─ 干渉判定
        ├─ 曲げ順評価
        ├─ 使用金型決定
        ├─ バックゲージ確認
        ├─ 加工可否判定
        │
        ▼
加工条件生成
        │
        ▼
現場加工
        │
        ▼
加工履歴・改善履歴蓄積
```

システムは加工条件を表示するだけではなく、

加工可能かどうかを判断するエンジンを中心として構成する。

---

# 3. システムの中心思想

本システムは

**「品番中心設計（Part-Centric Design）」**

を採用する。

すべての情報は品番を基準として管理する。

```text
品番
│
├── PDF図面
├── 3Dモデル
├── 曲げシミュレーション
├── 干渉判定
├── 曲げ順
├── 使用金型
├── バックゲージ
├── ワーク向き
├── 注意事項
├── 加工履歴
├── テスト加工履歴
├── 改善履歴
├── 写真
└── 動画
```

利用者は品番を検索するだけで、その部品に関するすべての情報へアクセスできる。

---

# 4. システムのコア

本システムの中核は

**「曲げシミュレーションエンジン」**

である。

エンジンの役割は以下とする。

- 3Dモデル表示
    
- 曲げ動作シミュレーション
    
- 干渉判定
    
- 曲げ順評価
    
- 使用金型評価
    
- バックゲージ確認
    
- 加工可否判定
    

加工条件は入力するものではなく、

シミュレーション結果として生成される情報と位置付ける。

# 6. システムが提供する価値

本システムが提供する価値は以下のとおりである。

- 技術の標準化
    
- 曲げ加工のデジタル化
    
- 加工条件の共有
    
- 技術継承
    
- 属人化の解消
    
- 加工品質の安定
    
- 新人教育時間の短縮
    
- ベテラン技術者の負担軽減
    
- 図面検索時間の削減
    
- テスト加工結果の資産化
    

---

# 7. 最も重要な画面

本システムで最も重要となる画面は、

**「部品詳細画面」**

である。

品番検索後、以下の情報を一画面で確認できる。

```text
部品詳細

────────────────────

① PDF図面

────────────────────

② 3Dモデル

────────────────────

③ 干渉判定結果

────────────────────

④ 加工条件

・曲げ順
・使用金型
・バックゲージ
・ワーク向き
・注意事項

────────────────────

⑤ 加工履歴

────────────────────

⑥ 改善履歴
```

現場では、この画面だけで加工を開始できることを目標とする。

---

# 8. システムで削減したいもの

本システムでは以下を削減する。

- 図面検索時間
    
- 加工開始までの時間
    
- 加工条件を考える時間
    
- ベテランへの確認回数
    
- 加工ミス
    
- 教育時間
    
- テスト加工回数
    

現場が「考える時間」を減らし、

「加工する時間」を増やすことを目的とする。

---

# 9. 理想の現場

新人でも基礎的な曲げ加工を理解していれば、

システムが加工条件・加工順・干渉結果を提示し、

誰でも同じ品質で加工できる環境を実現する。

ベテラン技術者は毎回加工方法を教えるのではなく、

新しい加工技術の開発や改善活動へ時間を使えるようにする。

# 12. システム理念

板金製造支援システムは、

単なる加工支援ソフトではない。

会社の技術を標準化し、

技術を「個人の経験」から「会社の資産」へ変えるための製造プラットフォームである。

加工技術は個人に依存するものではなく、

会社全体で蓄積・継承・改善され続ける資産である。

本システムは、その資産を支える中核システムを目指す。
