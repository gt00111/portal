# 1. 目的

本章では、板金製造支援システムの画面構成・画面遷移・画面レイアウト・画面IDを定義する。

本システムは、

**「現場が迷わない画面」**

を最優先とし、必要な情報を必要なタイミングで表示することで、設計者・現場担当者ともに直感的に操作できるUIを実現する。

また、本章では画面・機能・判断エンジン・データの関係も定義し、後続のDB設計・API設計・実装・テストの基準とする。

# 8. UI設計方針

- 現場が迷わないことを最優先とする。
    
- PDF図面を最も大きく表示する。
    
- 編集画面と閲覧画面を明確に分離する。
    
- 設計者・現場担当者で画面を分けず、権限のみ変更する。
    
- 技術情報は「技術ノート」として管理する。
    
- 判断エンジンの結果は視覚的に分かりやすく表示する。
    
- タブ構成を採用し、画面を増やしすぎない。
    
- 将来の機能追加にも対応できる構成とする。

# 11. 設計原則

画面は情報を表示する役割のみを持つ。

判断・解析・評価は判断エンジンが担当する。

技術情報はナレッジベースで管理する。

各コンポーネントの責務を明確に分離することで、保守性・拡張性・再利用性の高いシステムを実現する。

本システムは、

**「画面・判断エンジン・ナレッジベース」を分離した責務駆動設計（Responsibility-Driven Design）**を基本設計思想とする。
